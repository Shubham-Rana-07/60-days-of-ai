# Day 54 – HireLens: Resume & Job Description Keyword Extraction

## Objective

Built the keyword extraction layer for HireLens, an AI Resume Analyzer & Job Match Assistant.

## Work Completed

- Added static skills dictionary with 132 skills
- Organized skills into 11 categories
- Added resume keyword extraction
- Added job description keyword extraction
- Integrated keyword extraction with Flask application
- Tested PDF resume parsing
- Tested multiple resume and job-description combinations
- Added keyword visualization in the web interface

## Skills Categories

- Programming Languages
- Frameworks & Libraries
- Databases
- Cloud Platforms
- DevOps Tools
- Data Analytics
- AI/ML
- Web Technologies
- Testing
- Soft Skills
- Enterprise IT

## Result

HireLens can now extract relevant keywords separately from:
1. Resume
2. Job Description

This provides the foundation for the upcoming resume-job matching and scoring layer.
