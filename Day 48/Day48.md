# Day 48 – The Verdict Engine

## 📌 Objective

Build an AI-powered Decision Intelligence application that compares multiple options using verified research, transparent scoring, and adjustable user priorities.

---

## 🚀 Project

**The Verdict Engine**

An interactive web application that helps users compare career options using real-world research and dynamically weighted decision criteria.

---

## ✨ Features

- Live weighted scoring
- Adjustable criteria sliders
- Dynamic ranking updates
- Real-world citations
- Sources panel
- "How this was researched" section
- Responsive UI
- Loading and empty states
- Transparent decision methodology

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

---

## 📂 Project Files

- index.html
- sourced-data-report.md
- screenshots/

---

## 📚 Key Learnings

- Built a weighted decision engine.
- Learned to use transparent AI research with real citations.
- Improved frontend UI using HTML, CSS, and JavaScript.
- Implemented dynamic ranking based on user priorities.
- Understood the importance of explainable AI.
