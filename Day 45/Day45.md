# Day 45 – AI Decision Strategist

## Overview

Built an AI-powered Decision Strategist using Claude AI that guides users through a structured decision-making process and generates an interactive HTML Decision Report.

---

## Features

- Four-question guided interview
- Decision Matrix
- Assumption Buster
- Premortem Analysis
- 7-Day Test Plan
- Final Verdict
- Interactive HTML Dashboard
- Animated Progress Bars
- Responsive Design
- Shareable Summary Cards
