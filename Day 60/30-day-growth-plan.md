# HireLens — 30-Day Growth Plan

Transform HireLens v1.0.0 into a more reliable, maintainable and useful resume intelligence product.

| 30 | Prepare HireLens v1.1.0 release |

---

## Daily Rule

Each milestone should:

1. Start from the previous day's working code.
2. Implement one focused improvement.
3. Test the change.
4. Update documentation where necessary.
5. Commit the change.
6. Verify the application still works.

---

## Success Criteria

At the end of 30 days:

- Existing functionality remains stable.
- Test coverage is stronger.
- Resume parsing is more robust.
- Matching is more accurate.
- AI failures are handled gracefully.
- UI is more accessible.
- CI is established.
- Documentation is clearer.
- The next release is based on measurable improvements.
