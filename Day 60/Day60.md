## Final Project

HireLens is an AI-powered Resume Analyzer and Job Match Assistant developed as the final practical capstone of the AB Talks 60-Day Claude AI Challenge.

The application analyzes a resume against a target job description and provides:

- ATS compatibility scoring
- Resume-to-job matching
- Missing-skill detection
- Keyword analysis
- Resume keyword extraction
- AI-powered improvement suggestions
- Downloadable PDF reports
- Responsive web interface
