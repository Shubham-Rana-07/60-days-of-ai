# Day 51 – Capstone Project: Product Discovery & Sprint Planning

## Project Name
HireLens

## Project Description
HireLens is an AI-powered Job Match & Resume Analyzer designed for Indian IT job seekers. It compares resumes against job descriptions, calculates ATS compatibility, identifies missing skills, provides AI-powered resume improvement suggestions, and generates downloadable PDF reports.

## Deliverables
- Product Requirements Document (PRD)
- Day 2–10 Implementation Blueprint
- Project Pitch Deck

## Key Learnings
- Importance of product discovery before coding.
- Defining a realistic v1.0 scope.
- Preventing scope creep.
- Designing a hybrid AI architecture.
- Writing professional product documentation.
