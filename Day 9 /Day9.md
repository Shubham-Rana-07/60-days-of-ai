# Day 9 – NutriScope (Claude Artifacts)

## Overview

NutriScope is an AI-powered Nutrition Analytics application built using **Claude Artifacts**. The project follows an **MVP-first development approach**, where the core functionality was implemented first and then enhanced through iterative improvements.

This approach made the application easier to develop, test, and extend while maintaining a clean and organized codebase.

---

## MVP Features

* User profile management
* Food logging system
* Daily nutrition tracking
* Macro and micronutrient calculations
* Interactive dashboard
* Basic food recommendations
* Responsive dark-themed interface

---

## Enhanced Features

* CSV food data upload
* Expanded food database (60+ food items)
* Advanced micronutrient tracking
* Two-day meal planner
* Nutrition risk analysis
* Improved charts and visualizations
* Nutrition references and educational disclaimer
* Smarter recommendation engine
* Enhanced UI with animations

---

## MVP vs Enhanced

| MVP                      | Enhanced                     |
| ------------------------ | ---------------------------- |
| Basic nutrition tracking | Advanced nutrition analysis  |
| 20 food items            | 60+ food items               |
| Basic dashboard          | Rich interactive dashboard   |
| Simple recommendations   | Personalized recommendations |
| Standard UI              | Enhanced UI & animations     |

---

## Key Learning

This project reinforced the importance of **iterative development**. Building a functional MVP before adding advanced features resulted in a cleaner architecture, improved maintainability, and a more structured development process.

Instead of relying on a single large prompt, breaking the project into multiple development stages produced more reliable and higher-quality results.
